# FridgePolice

A tiny roommate fridge-sharing prototype for portion requests, approvals, reservations, spoiled food, and reality-based inventory corrections. See [Changes.md](./Changes.md) for scenario-by-scenario behavior and engineering decisions.

## Run locally

Requires Node.js 20 or newer. There are no external dependencies.

```sh
npm test
npm start
```

Visit [http://127.0.0.1:4173](http://127.0.0.1:4173). The app saves the demo state in your browser's local storage; use **Reset demo** to start over.
